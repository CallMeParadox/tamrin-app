# اپلیکیشن هوشمند تمرین بدنسازی (Tamrin App) 🏋️‍♂️

یک اپلیکیشن تخصصی و آفلاین برای ثبت تمرینات بدنسازی با الهام از مکانیک‌های محبوب Hevy و Strong، کاملاً بومی‌سازی شده به زبان فارسی و با پشتیبانی کامل از RTL.

## ✨ ویژگی‌های کلیدی
- **لاگر حرفه‌ای تمرینات**:
  - ثبت ست‌ها به همراه وزن (kg)، تکرار (Reps) و شاخص RPE
  - دسته‌بندی انواع ست: ست عادی، گرم‌کردن (W)، دراپ‌ست (D) و تا مرز شکست (F)
  - محاسبه لحظه‌ای تخمین ۱ تکرار بیشینه (1RM) بر اساس فرمول علمی Epley
- **کتابخانه حرکات ایرانی**:
  - نام‌های استاندارد فارسی و انگلیسی
  - عضلات هدف و تجهیزات
  - نکات بیومکانیکی و ایمنی اجرای صحیح
- **ابزارهای پیشرفته بدنسازی**:
  - **محاسبه‌گر صفحات هالتر (Plate Calculator)**: محاسبه خودکار تعداد صفحات ۲۵، ۲۰، ۱۵، ۱۰، ۵، ۲.۵ و ۱.۲۵ کیلوگرم برای هر طرف میله هالتر
  - **محاسبه‌گر 1RM و درصدهای تمرینی**: جدول درصدهای ۶۰٪ تا ۹۵٪ جهت برنامه‌ریزی تمرینات قدرتی و هایپرتروفی
  - **تایمر استراحت بین ست‌ها**: تایمر شمارش معکوس با بازه‌های پیشنهادی
- **تحلیل پیشرفت**:
  - ردیابی حجم هفتگی هر گروه عضلانی (تعداد ست‌های موثر)
  - ثبت خودکار رکوردهای شخصی (PRs) برای هر حرکت
  - ذخیره‌سازی آفلاین و کامل داده‌ها (Offline-First)
